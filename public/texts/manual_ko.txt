📖 5DO 사용자 매뉴얼

1. 소개

5DO(5th Density Oscillator)는 주파수와 공명 사운드를 통해 공간의 에너지를 조율하는 차세대 사운드 웰니스 플랫폼입니다. 주파수 라이브러리, 주파수 생성기, 소울 코드(AI 영혼 분석), CE5 프로토콜 등의 핵심 기능을 제공합니다.

⸻

2. 접속 방법

웹 브라우저에서 5do.app에 접속하세요. 별도 설치 없이 바로 사용할 수 있습니다. 홈화면에 추가하면 PWA 앱 형태로 구동됩니다. Bluetooth, AUX, USB-DAC 출력 장치 연결을 권장합니다.

⸻

3. 주파수 라이브러리

다양한 카테고리의 주파수·명상 사운드를 제공합니다:
• 솔페지오 주파수
• 차크라 활성화
• 명상 & 호흡
• 뇌파 상태
• 크리스탈 주파수
• RIFE 주파수
• 신체 장기 주파수
• 토러스 하모닉스
• 자연 공명
• 디바인 튠즈

3-1. 트랙 재생
• 폴더 썸네일을 눌러 카테고리에 진입합니다.
• 트랙을 선택하면 재생 화면으로 전환됩니다.
• 재생/일시정지, 정지, 루프, 타이머 기능을 제어할 수 있습니다.

3-2. 즐겨찾기
• 트랙 리스트나 재생 화면에서 ★ 아이콘을 눌러 즐겨찾기를 등록합니다.
• 라이브러리 상단의 Favorites 섹션에서 바로 접근할 수 있습니다.
• 별 필터 버튼(☆)으로 즐겨찾기만 표시할 수 있습니다.

3-3. 검색
• 검색 바에서 폴더명 또는 곡명으로 검색할 수 있습니다.
• 검색 모드(폴더/곡명)를 전환하여 원하는 방식으로 탐색하세요.

3-4. 플레이리스트
• 재생 화면의 플레이리스트 버튼으로 나만의 재생 목록을 만들 수 있습니다.
• 현재 트랙을 추가하거나, 목록을 내보내기/가져오기 할 수 있습니다.

⸻

4. 사운드 믹서

재생 화면 하단의 3-way 토글 스위치로 사운드 레이어를 제어합니다:

4-1. 자연음 믹스 (왼쪽 포지션)
• 빗소리, 숲, 파도, 브라운/핑크/화이트 노이즈 중 선택합니다.
• 크로스페이드 슬라이더로 트랙과 자연음의 믹스 비율을 조절합니다.

4-2. OFF (중앙 포지션)
• 주파수·명상 트랙만 단독 재생합니다.

4-3. BGM 믹스 (오른쪽 포지션)
• Divine Tunes 컬렉션에서 배경음악을 선택합니다.
• 크로스페이드 슬라이더로 트랙과 BGM의 믹스 비율을 조절합니다.
• Divine Tunes 카테고리 재생 시에는 믹서가 자동으로 비활성화됩니다.

⸻

5. 주파수 생성기

생성기 탭 상단의 서브탭으로 두 도구를 전환할 수 있습니다 — 주파수 생성기(소리 만들기) / 주파수 측정기(소리 분석).

5-1. 주파수 생성기
1Hz ~ 20kHz 범위의 주파수를 직접 생성하고 재생할 수 있습니다.
• 파형 선택: 사인파, 사각파, 삼각파, 톱니파
• 바이노럴 모드: 좌우 채널에 다른 주파수를 출력 (헤드폰 권장)
• 듀얼 톤 믹서: 두 개의 주파수를 동시에 재생
• 하모닉스: 배음 구조를 추가하여 풍성한 음색 생성
• 반송파 / 변조: 가청 반송파를 프로그램 주파수로 진폭변조합니다. 7.83Hz(슈만) 같은 초저주파는 스피커·헤드폰이 사실상 재생하지 못하는데, 반송파에 실으면 전달됩니다.
  · 반송파 주파수 20Hz~20kHz, 변조 깊이 0~100%, 반송파 파형 4종
  · AM(반송파 유지) / 링 변조(반송파 억압) 중 선택
  · 패널 하단에 실제 출력 성분(반송파 ± 프로그램 주파수)이 표시됩니다. 프로그램 주파수 자체는 음파가 아니라 포락선으로 전달됩니다.
  · 하모닉스·바이노럴·듀얼 톤과 함께 사용할 수 있고, WAV 내보내기에도 그대로 반영됩니다.
• 프리셋: 자주 사용하는 주파수를 저장하고 불러오기
• WAV 내보내기: 생성한 주파수를 오디오 파일로 저장

5-2. 주파수 측정기 (v3.9 신규)
내장 마이크로 주변 소리의 기본 주파수(F0)를 실시간 분석합니다.
• 오실로스코프: 파형을 ~3 사이클 자동 스케일로 안정 표시
• 피치 디텍터: 자기상관 알고리즘으로 30Hz~2kHz 범위 검출
• 튜너: 가장 가까운 음(A4 등) + cents 편차(±50¢) 표시, ±10¢ 이내 녹색
• 로그 스케일 스펙트럼: 20Hz ~ 5kHz 72-bar
• 사용 예시: 악기 튜닝, 생성기 주파수 검증, 튜닝 포크/싱잉볼 측정
* 오디오는 로컬 브라우저에서만 처리되며 서버로 전송되지 않습니다.

6. 소울 코드 (Soul Code)

AI 기반 영혼 분석 + 공명 주파수 생성기입니다.
점성학, 사주명리학, 아카식 레코드를 통합 분석합니다.

입력 정보:
• 생년월일 (양력/음력), 출생 시간, 출생 장소
• 성별, 혈액형, MBTI, 의도(Intention)

분석 내용:
• 서양 점성학 (별자리, 행성 지배성, 원소)
• 동양 명리학 (사주팔자 — 만세력 기반 정확한 계산)
• 스타시드 계보 (Pleiadian, Sirian, Arcturian 등 10계열)
• 아카식 레코드 영혼 원형
• 오행 밸런스 분석
• 월별 운세 가이드 (천문 이벤트 포함)

출력:
• 맞춤형 에너지 리포트 (한/영 동시)
• 개인 공명 주파수
• 최적화된 PEMF 주파수 대역
• 차크라 활성화 가이드
• PDF 리포트 다운로드

7. 데일리 레조넌스 (Daily Resonance)

Soul Code 블루프린트 기반으로 매일 갱신되는 개인 공명 리포트입니다.
• 오늘의 에너지 시그니처 — 달/행성 배치, 주요 각도
• 지자기 활동 — NOAA Kp 지수, 슈만 공명 상태
• 오늘의 주파수 매치 — 블루프린트 해시로 결정론적 트랙 추천
• AI 라이프 가이드 — 오늘 하루 의식 가이드 + Ritual 액션
• 비주얼 저니 — Particle Life 개인화 애니메이션
* 블루프린트가 저장되지 않은 경우 Soul Code 분석을 먼저 실행하세요.

11. 설정

• 언어 전환: 상단 우측 토글 스위치로 한국어/영어 전환
• 테마: 햄버거 메뉴 > Backdrop에서 6종 테마 + 배경/UI 투명도 조절
• 반복 재생, 타이머, 루프 기능
• 구독 관리: 프로필 > 구독에서 플랜 변경/해지 (토스페이먼츠 연동)

12. 문제 해결

• 소리가 안 들릴 경우 → 화면을 한 번 터치하고 출력 장치를 확인하세요.
• 재생이 안 될 경우 → 새로고침 후 다시 시도하세요.
• 출력이 약할 경우 → 볼륨을 올리거나 다른 출력 모드를 시도해보세요.
• Particle Life가 작동하지 않을 경우 → WebGPU 미지원 브라우저 (iOS Safari 17 이하, 일부 Android)에서는 WebGL 폴백이 자동 적용됩니다.
• 데일리 레조넌스에 블루프린트 없음 안내 → Soul Code 탭에서 먼저 분석을 실행하세요.
