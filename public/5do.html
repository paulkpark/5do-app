주파수 생성기

내 마음대로 조율하는 나만의 주파수 생성기
소개 · 빠른 매뉴얼 · v4.2

1두 가지 도구, 하나의 탭

상단 서브탭으로 두 도구를 바로 전환합니다. 주파수 생성기로는 1Hz~20kHz 범위의 신호를 직접 만들고, 주파수 측정기로는 내장 마이크를 통해 들어오는 소리의 기본 주파수를 실시간으로 분석합니다.

생성기에서 만든 주파수를 측정기로 즉석에서 검증하거나, 악기·튜닝 포크·싱잉볼 등 외부 소리의 정확한 주파수를 확인할 수 있어요.

2주파수 생성기 기능

• 주파수 슬라이더 / 다이얼 / 키패드 입력 • 4가지 파형: 사인, 사각, 삼각, 톱니 • 하모닉스 — 옥타브 스택 또는 11차 배음 (Holland OPEF) 모드 (NEW v4.2) • 바이노럴 비트 (좌우 채널 분리) • 듀얼 톤 (두 주파수 동시 재생) • L/R 밸런스 슬라이더 — 좌·우 채널 비율 실시간 조절 • WAV 파일 내보내기 (밸런스 반영) • 프리셋 저장/불러오기 • 오실로스코프 실시간 시각화

3주파수 측정기 기능

• 내장 마이크 실시간 분석 (30Hz ~ 2kHz) • 자기상관(autocorrelation) 피치 디텍터 • 3대 리드아웃: Hz · 음(A4 등) · 튜닝 편차(cents) • 튜너 니들 — ±10¢ 이내 녹색 "튜닝 완료" • Peak-normalize 오실로스코프 (자동 스케일) • 로그 스케일 스펙트럼 (20Hz~5kHz, 72 bars) • 오디오는 로컬 브라우저에서만 처리 · 서버 미전송

4빠른 사용법

1. 생성기에서 주파수 입력 → 파형 선택 → 재생 2. 측정기 서브탭 탭 → 측정 시작 → 마이크 허용 3. 자동으로 오실로스코프 + Hz + 음 + cents 실시간 표시 4. 튜너 니들이 녹색이면 정확히 튜닝된 상태 5. (선택) 프리셋 저장 또는 WAV 내보내기
